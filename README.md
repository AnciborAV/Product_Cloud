# Зелёная лавка

Учебная витрина продуктового магазина: Java 25, Spring Boot 4.1.2, Spring MVC, Thymeleaf и Jakarta Validation.

## Запуск

Нужен JDK 25. Maven устанавливается автоматически через Maven Wrapper; при первом запуске нужен доступ к Maven Central.

```sh
./mvnw spring-boot:run
```

Откройте http://localhost:8080. Если порт занят, используйте:

```sh
./mvnw spring-boot:run -Dspring-boot.run.arguments=--server.port=8081
```

## Проверка

```sh
./mvnw clean verify
```

Тесты проверяют ограничения модели, точность денежных значений, поиск и категории, неизменяемость снимков каталога, конкурентное добавление, HTTP-маршруты, рендеринг Thymeleaf, ошибки формы, перенаправление после добавления и экранирование HTML.

## Устройство приложения

- `model`: неизменяемый `Product` (record), цена `BigDecimal`, категории `Category`.
- `service`: каталог с демонстрационными товарами, поиск, фильтрация и потокобезопасное добавление.
- `controller`: обработка запросов, отдельная форма с Jakarta Validation, Post/Redirect/Get после успешного добавления.
- `templates/products.html`, `static/css/store.css`: адаптивная русскоязычная витрина с серверным рендерингом. JavaScript для работы не требуется. Иллюстрации используют системные эмодзи; внешний шрифт Google Fonts необязателен, предусмотрен системный запасной шрифт.

`GET /` и `GET /products` показывают каталог. Параметры `q` и `category` можно комбинировать; например `/products?q=молоко&category=DAIRY`. `POST /products` принимает `name`, `price`, `category`, `unit`.

Это учебный каталог: данные находятся в памяти и сбрасываются при перезапуске. Добавление открыто для всех посетителей. Заказы, оплата, авторизация и база данных в проект не входят. Для небольшого каталога выбран `CopyOnWriteArrayList`: чтение не блокирует другие запросы, наружу возвращаются неизменяемые снимки. Для большого каталога понадобится постоянное хранилище и пагинация.
