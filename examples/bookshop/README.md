# Тихая полка — магазин и личная PDF-библиотека

Самостоятельное Java MVC-приложение в `examples/bookshop`. PostgreSQL хранит каталог, заказы, пользователя, полки и сами PDF-файлы. Thymeleaf формирует HTML на сервере. Интерфейс адаптирован к компьютеру и телефону: книжные обложки, спокойные цвета, поиск, фильтры, корзина и личная библиотека.

## Возможности

- Первый запуск: создать единственного владельца, указав email и пароль.
- Вход, выход, сессия на 8 часов; PDF недоступен по прямой ссылке без входа.
- Создать полку по автору или теме; загрузить PDF (до 20 МБ), указать название и автора.
- Читать PDF в новой вкладке штатным просмотрщиком браузера или скачать файл.
- Искать по автору/названию, фильтровать по полкам, переносить книгу на другую полку.
- Учебный магазин: 6 начальных книг, категории, поиск, корзина, сохранение заказа и чек.
- Полки, PDF и заказы сохраняются после перезапуска. Корзина хранится в браузере.
- В коде русские комментарии, JUnit-тесты и CI с настоящей PostgreSQL.

## Запуск на MacBook в IntelliJ IDEA

Требования: **JDK 17 или новее (включая JDK 25)** и работающая PostgreSQL. Maven Wrapper находится в корне Product_Cloud; отдельный Maven не нужен. При первой сборке нужен интернет для загрузки зависимостей.

1. Получите ветку `feature/quiet-shelf-library` репозитория Product_Cloud.
2. В IntelliJ выберите **File → Open** и откройте именно `examples/bookshop/pom.xml` как отдельный проект. Укажите установленный JDK в Project SDK.
3. Создайте отдельную пустую базу, например через Query Tool в pgAdmin, подключённый к базе `postgres`:

   ```sql
   CREATE DATABASE quiet_shelf;
   ```

   Пользователь PostgreSQL, под которым будет запущено приложение, должен иметь право создавать таблицы в этой базе. Не указывайте базу Product Cloud.

4. Откройте `BookshopApplication.java`. Создайте конфигурацию запуска **Application** с главным классом `ru.aav.bookshop.BookshopApplication` и модулем `quiet-shelf`. В **Environment variables** задайте:

   ```text
   SHOP_DB_URL=jdbc:postgresql://localhost:5432/quiet_shelf
   SHOP_DB_USER=postgres
   SHOP_DB_PASSWORD=пароль_вашего_пользователя_PostgreSQL
   ```

   Если у вас другой пользователь или порт PostgreSQL, измените значения. Это пароль базы, он НЕ является паролем входа в библиотеку. Пароли не сохраняйте в общем репозитории.

5. Нажмите Run. Откройте **http://localhost:8081/library**.
6. На странице первого запуска введите свой email и выбранный пароль приложения. Повторная регистрация владельца будет закрыта. После входа откроется личная библиотека.
7. Нажмите **+** рядом с «Мои полки», создайте полку, затем **Загрузить PDF**. После загрузки нажмите **Читать**.

Если PDF в браузере автоматически скачивается, включите встроенный просмотр PDF в настройках браузера. Приложение отдаёт файл с `Content-Type: application/pdf` и `Content-Disposition: inline`.

### Запуск из терминала

Из корня репозитория:

```bash
export SHOP_DB_URL='jdbc:postgresql://localhost:5432/quiet_shelf'
export SHOP_DB_USER='postgres'
# Введите пароль PostgreSQL без сохранения в истории команд:
read -s SHOP_DB_PASSWORD
export SHOP_DB_PASSWORD
bash examples/bookshop/run.sh
```

На macOS команда `read -s SHOP_DB_PASSWORD` работает в zsh и bash. Остановка — Ctrl+C. Для другого HTTP-порта задайте VM option `-Dshop.port=8082` в IntelliJ.

## Как устроен MVC

| Слой | Классы / файлы | Задача |
|---|---|---|
| Сборка приложения | `BookshopApplication` | Соединяет зависимости и запускает HTTP-сервер JDK |
| Контроллеры | `AuthController`, `ShopController`, `LibraryController` | Проверяют вход, разбирают HTTP-запросы, выбирают ответ |
| Логика | `ShopService`, `LibraryService`, `AuthService` | Проверки, расчёт заказа, работа с библиотекой и сессиями |
| Модели | `Book`, `Order`, `LibraryDocument` | Данные предметной области |
| Модель представления | `BookView` | Подготавливает цену для отображения |
| Представление | `ShopView`, `web/*.html` | Передаёт модели в настоящие Thymeleaf-шаблоны |
| Данные | `Database`, `*Repository`, `db/schema.sql` | JDBC, SQL, транзакции и PostgreSQL |
| Интерфейс | `style.css`, `shop.js`, `library.js`, `auth.js` | Адаптивная вёрстка, диалоги, поиск и отправка запросов |

Это небольшой MVC без Spring, чтобы явно показать весь путь запроса. Например: «Загрузить PDF» → `AuthController` проверяет сессию → `LibraryController` принимает файл → `LibraryService` проверяет размер/сигнатуру/поля → `LibraryRepository` записывает `BYTEA` → Thymeleaf отображает обновлённую полку. Для магазина расчёт суммы выполняет Java-сервис, а не браузер.

## Тесты

Быстрые тесты не требуют БД:

```bash
bash examples/bookshop/test.sh
```

JUnit проверяет арифметику денег, неизменяемость заказа, недопустимые количества/файлы, хеширование паролей, все Thymeleaf-шаблоны и экранирование HTML.

Для интеграционных тестов создайте **отдельную** базу:

```sql
CREATE DATABASE quiet_shelf_test;
```

Затем из корня репозитория:

```bash
export SHOP_TEST_DB_URL='jdbc:postgresql://localhost:5432/quiet_shelf_test'
# SHOP_DB_USER и SHOP_DB_PASSWORD — учётные данные PostgreSQL, как выше.
bash examples/bookshop/test.sh
```

**Тесты очищают таблицы только выделенной базы `quiet_shelf_test`**. Имя проверяется перед очисткой. Без `SHOP_TEST_DB_URL` интеграционные тесты явно пропускаются. CI запускает все 10 тестов на PostgreSQL 16 с Java 17 и 25.

Интеграционные сценарии: запись/повторное чтение заказа; откат при ошибке внешнего ключа; сохранность байтов PDF и перенос между полками; невозможность заменить владельца; отзыв сессии; HTTP-цепочка «регистрация → полка → загрузка → чтение → заказ → выход» и запрет анонимного доступа к PDF.

## Хранение и ограничения

- `books`, `orders`, `order_items` — магазин; `app_user`, `shelves`, `documents` — личная библиотека.
- Таблицы создаются автоматически. Начальные книги добавляются через `ON CONFLICT DO NOTHING`, существующие записи не перезаписываются.
- Пароли хешируются PBKDF2-HMAC-SHA256, 600 000 итераций, случайная соль. Cookie: HttpOnly, SameSite=Strict; сессии в памяти. После перезапуска нужно войти снова.
- Приложение привязано к `127.0.0.1` и рассчитано на одного владельца за своим компьютером. Оно не опубликовано в интернете и не доступно с другого компьютера/телефона. Для публичного размещения нужны отдельная настройка HTTPS, Secure cookie и эксплуатационная защита.
- PDF хранится в PostgreSQL целиком, максимум 20 МБ на файл. Проверяется заголовок `%PDF-`, а не безопасность содержимого. Загружайте доверенные PDF. Открытие выполняет просмотрщик браузера; позиция чтения приложением не сохраняется.
- Магазин демонстрационный: нет платежей, доставки и складского учёта. Личная библиотека сохраняет реальные пользовательские файлы.
- Удаление книги/полки, восстановление пароля по email и несколько аккаунтов в эту версию не входят. Email служит логином, письма не отправляются.
- Резервная копия: `pg_dump -U postgres -Fc quiet_shelf > quiet_shelf.backup`. Она включает PDF и хеш пароля. Храните её отдельно от репозитория.

## Ориентир для изучения

Начните с `BookshopApplication`, затем `AuthController` → `LibraryController` → `LibraryService` → `LibraryRepository`. После этого изучите `ShopView` и `library.html`. Первая цепочка показывает движение данных, вторая — их отображение. Учебный магазин находится по адресу `/`, личная библиотека — `/library`.
